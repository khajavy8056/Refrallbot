# انتخاب هاست — چه چیزی بخریم؟

این سند به تصمیم «چه هاستی تهیه کنم» پاسخ می‌دهد: cPanel کافی است یا دایرکت‌ادمین،
VPS لازم است یا نه، و برای تست روی گوشی چه کنیم.

## خلاصهٔ تصمیم

| سناریو | پیشنهاد |
|---|---|
| **راه‌اندازی واقعی ربات (توصیه‌شده)** | **هاست اشتراکی cPanel** با PHP 8.1+، MySQL 5.7+/8.0+ و SSL رایگان |
| بخواهید خودتان کنترل کامل داشته باشید | VPS ارزان + کنترل‌پنل (نه لازم، نه آسان‌تر) |
| **فقط تست روی گوشی، بدون خرید** | رایگان: https://studio.bh.sh یا PocketHost / یا اجرای محلی + ngrok |
| دایرکت‌ادمین | **نه، لازم نیست.** پشتیبانی می‌شود ولی برای این پروژه هیچ مزیتی بر cPanel ندارد |

## ۱. پس cPanel یا DirectAdmin؟

هر دو «کنترل‌پنل هاست اشتراکی» هستند و پروژه با هر دو کار می‌کند؛ تفاوتشان اداری است نه فنی.
RefrallBot فقط این‌ها را لازم دارد: **PHP 8.1+**، **MySQL**، **mod_rewrite**، **.htaccess**، **Cron Jobs**، **SSL**.

- **cPanel** — رایج‌تر است، آموزش و پشتیبانی بیشتری دارد، اینترنت مملو از راهنما برایش است. آنچه تست‌ها با آن سنجیده شده همین است.
- **DirectAdmin** — ارزان‌تر (بسیاری از هاست‌های ایرانی/اروپایی)، سبک‌تر. همان امکانات را دارد ولی نام منوها فرق دارد (مثلاً «MySQL Management» به‌جای «MySQL® Databases»).

**نتیجه:** ارزان‌تر و در دسترس‌تر را بگیرید. اگر تازه‌کار هستید cPanel انتخاب امن‌تری است چون هر مشکلی را با جست‌وجو حل می‌کنید. **هیچ قابلیتی از پروژه به cPanel وابسته نیست** — نه API خاصی صدا می‌زنیم، نه از ابزار اختصاصی‌اش استفاده می‌کنیم.

> ⚠️ یک استثنا: اگر هاست‌دهنده‌تان **mod_rewrite** را خاموش کند یا اجازهٔ `.htaccess` ندهد، باید
> از حالت «docroot = public/» استفاده کنید. این را قبل از خرید از پشتیبانی بپرسید.

## ۲. مشخصاتی که باید در پلن باشد

| مورد | حداقل | توصیه |
|---|---|---|
| PHP | 8.1 | 8.2 یا 8.3 |
| MySQL / MariaDB | 5.7 / 10.2 | 8.0 / 10.6 |
| افزونه‌ها | `pdo_mysql`, `mbstring`, `openssl`, `json` | + `curl`, `fileinfo` |
| فضای دیسک | ۳۰۰ مگابایت | ۱ گیگابایت |
| Cron Jobs | ۱ مورد (حداقل هر ۵ دقیقه) | ۲ مورد (هر دقیقه برای Polling) |
| SSL | لازم | Let's Encrypt رایگان از خود پنل |
| PHP-FPM / LiteSpeed | هر دو خوب | `mod_php` هم کار می‌کند |

**مواردی که لازم نیست** (و پول اضافه ندهید): Node.js، Redis، Composer، SSH، dedicated IP، «PHP Selector» حرفه‌ای.

### هشدارهای مهم هنگام خرید

1. **Cron حداقل هر ۵ دقیقه** — اگر پلن فقط cron روزانه/ساعتی دارد، ارسال همگانی و کمپین‌ها کند می‌شوند (کار می‌کند ولی کند). این را حتماً بپرسید.
2. **`exec`/`proc_open` غیرفعال است؟** اشکالی ندارد؛ فقط تست خودکار داخلی (`php tests/run_all.php`) اجرا نمی‌شود — خودِ برنامه به آن نیازی ندارد.
3. **`allow_url_fopen` خاموش باشد** — برنامه با cURL کار می‌کند، پس مشکلی نیست.
4. **محدودیت `max_execution_time`** (معمولاً ۳۰–۶۰ ثانیه در اشتراکی): ارسال همگانی به‌صورت دسته‌ای و با Cron انجام می‌شود، پس برای صدها هزار کاربر هم روی هاست اشتراکی قابل استفاده است.
5. **هاست اشتراکی و ریسک تلگرام:** اگر ربات رشد کرد و به محدودیت منابع خورد، مهاجرت به VPS ساده است (فقط `.env` و دیتابیس را منتقل می‌کنید).

## ۳. مراحل خرید تا راه‌اندازی (cPanel)

1. دامنه بگیرید (هر ثبت‌کننده‌ای) یا از ساب‌دامین رایگان هاست استفاده کنید.
2. پلن اشتراکی با مشخصات بالا بخرید.
3. در cPanel → **Select PHP Version** → PHP 8.2 و افزونه‌های جدول بالا را فعال کنید.
4. **SSL/TLS Status** → Let's Encrypt → `Force HTTPS Redirect`.
5. **MySQL® Databases** → یک دیتابیس + یک کاربر بسازید و کاربر را با «All Privileges» به دیتابیس اضافه کنید. نام‌ها را جایی یادداشت کنید (معمولاً پیشوند `user_` دارند).
6. فایل ZIP پروژه را در **File Manager** → `public_html` آپلود و Extract کنید.
7. `https://YOUR-DOMAIN/install.php` را باز کنید و ویزارد را کامل کنید (راهنما: [INSTALL.md](INSTALL.md)).
8. Cron و Webhook را تنظیم کنید ([BOT-SETUP.md](BOT-SETUP.md)).

## ۴. تست روی گوشی بدون خرید هاست

سه گزینه، از ساده به پیچیده:

### الف) هاست رایگان PHP با پشتیبانی MySQL
مثل **https://studio.bh.sh** (هاست PHP رایگان با MySQL) یا سرویس‌های مشابه.
پروژه را آپلود می‌کنید و `install.php` را در مرورگر گوشی باز می‌کنید. محدودیت‌ها: منابع کم، ممکن است HTTPS/دامنهٔ موقت بدهند و Cron نداشته باشند — برای «ببینم کار می‌کند» کافی است.

> برای Mini App (پنل وب کاربران) تلگرام **HTTPS معتبر** می‌خواهد؛ روی سرویس‌های رایگان معمولاً https دارید، پس پنل وب هم باز می‌شود. اگر نبود، همه‌چیز از دکمه‌های ربات انجام می‌شود.

### ب) اجرا روی لپ‌تاپ + تونل عمومی (ngrok / cloudflared)
اگر لپ‌تاپتان درگیر است، این را روی موبایل انجام ندهید — روی همان لپ‌تاپ یا یک ماشین دیگر:

```bash
php -S 0.0.0.0:8080 -t public public/index.php
# در ترمینال دیگر:
ngrok http 8080     # یا: cloudflared tunnel --url http://localhost:8080
```
آدرس `https://XXXX.ngrok-free.app` را در گوشی باز کنید و وبهوک تلگرام را روی همان تنظیم کنید. (نکته: `php -S` تک‌رشته‌ای است؛ برای تست UI عالی است، برای بار واقعی نه.)

### ج) VPS ارزان رایگان-آزمایشی
اکثر ارائه‌دهنده‌ها (Hetzner، DigitalOcean، Contabo، …) سرور آزمایشی می‌دهند. روی آن Apache/Nginx + PHP + MySQL نصب و پروژه را اجرا می‌کنید. اگر می‌خواهید هم‌زمان هم تست کنید هم یاد بگیرید، این گزینه بیشترین کنترل را می‌دهد.

## ۵. «برنامه اندروید» نداریم — و لازم هم نیست

RefrallBot یک **برنامه وب** است، نه اپ نیتیو اندروید. برای گوشی سه راه دارید:

1. **همین سایت در مرورگر گوشی** — کاملاً واکنش‌گرا و RTL است (پنل مدیر و پنل کاربر).
2. **«افزودن به صفحه اصلی»** — در Chrome اندروید منو → *Add to Home screen*. آیکون روی صفحه اصلی می‌آید و شبیه اپ باز می‌شود (PWA سبک؛ نیازی به کد اضافه نیست).
3. **Mini App تلگرام** — پنل کاربر داخل تلگرام؛ فقط به دامنه + HTTPS معتبر نیاز دارد.

اگر واقعاً APK می‌خواهید، تنها کار منطقی **WebView wrapper** است (اپی که همین سایت را نمایش می‌دهد) — و برای ربات معرفی، مزیتی بر «افزودن به صفحه اصلی» ندارد.

## ۶. هزینهٔ تقریبی

- دامنه: ~۱۰–۱۵ دلار/سال
- هاست اشتراکی cPanel: ~۲–۵ دلار/ماه
- SSL: رایگان
- **مجموع: کمتر از ۵ دلار در ماه** — برای شروع کافی است.
