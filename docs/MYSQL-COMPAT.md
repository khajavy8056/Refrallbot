# سازگاری با MySQL — گزارش بازبینی

این سند نتیجهٔ بازبینی کامل کد برای اجرا روی **MySQL واقعی** است (چون تست‌های
خودکار روی SQLite اجرا می‌شوند و برخی خطاها فقط روی MySQL ظاهر می‌شوند).

> **تاریخ بازبینی:** ۲۰۲۶-۱۱-۱۷ · **نسخهٔ MySQL هدف:** 5.7، 8.0، MariaDB 10.2+

## خلاصه

| وضعیت | تعداد |
|---|---|
| باگ مسدودکنندهٔ نصب که پیدا و رفع شد | **۳** |
| مقاوم‌سازی (جلوگیری از خطای بی‌صدا) | **۲** |
| بررسی موفق (بدون مشکل) | ۱۱ |
| تست رگرسیون خودکار جدید | ۱۱ بررسی در `tests/_mysql_ddl.php` |

## باگ‌های پیدا و رفع‌شده

### ۱. ستون `id` در `CREATE TABLE` ساخته نمی‌شد — خطای ۱۰۷۲ ⛔ مسدودکننده

`SchemaBuilder::toSql()` هر ستونی که در `PRIMARY KEY` بود را از تعریف جدول
حذف می‌کرد. در MySQL نوع `id` برابر `BIGINT UNSIGNED NOT NULL AUTO_INCREMENT`
است و کلید اصلی جداگانه با `PRIMARY KEY (id)` اعلام می‌شود؛ بنابراین MySQL
می‌گفت `Key column 'id' doesn't exist in table` و **هیچ‌یک از ۲۹ جدول ساخته نمی‌شد**.

روی SQLite هرگز دیده نمی‌شد، چون نوع `id` در SQLite خودش شامل `PRIMARY KEY` است.

**رفع:** همهٔ ستون‌ها بدون استثنا در `CREATE TABLE` نوشته می‌شوند.

### ۲. `SELECT key, value FROM system_settings` — خطای سینتکس، بی‌صدا ⛔ مسدودکننده

`key` در MySQL کلمهٔ رزروشده است. کوئری خطای سینتکس می‌داد و چون داخل
`try/catch` بود، **همهٔ تنظیمات سامانه بی‌صدا خالی برمی‌گشتند**: نام سامانه،
پیکربندی کمیسیون، توکن کرون، حداقل برداشت، حالت پنل وب و…

**رفع:** `SELECT \`key\`, \`value\` FROM system_settings`.

### ۳. `CREATE INDEX IF NOT EXISTS` — MySQL آن را نمی‌شناسد ⛔ مسدودکننده

این عبارت مخصوص MariaDB و SQLite است. مرحلهٔ ۳ ویزارد نصب روی MySQL با
خطای سینتکس متوقف می‌شد.

**رفع:** `CREATE INDEX` ساده + بررسی وجود ایندکس با `Database::indexExists()`
قبل از اجرا (تا اجرای تکراری Migration خطای Duplicate ندهد).

## مقاوم‌سازی‌ها

### ۴. `ON DELETE SET NULL` روی ستون `NOT NULL` — خطای ۱۸۳۰

`admins.role_id` اجباری بود ولی `SET NULL` داشت. **رفع:** برای ستون‌های اجباری
خودکار `CASCADE` استفاده می‌شود.

### ۵. `insertIgnore` در برابر مسابقهٔ همزمانی

الگوی «SELECT سپس INSERT» تحت بار همزمان می‌توانست Duplicate key بدهد.
**رفع:** خطای `1062`/`23000` بلعیده می‌شود و `false` برمی‌گردد (رفتار idempotent تضمین‌شده).

### ۶. `SET SESSION sql_mode` و `SET NAMES` دیگر اتصال را نمی‌شکنند

بعضی هاست‌های اشتراکی اجازهٔ تغییر `sql_mode` نمی‌دهند. قبلاً خطای «Access
denied» کل اتصال را از کار می‌انداخت. **رفع:** در `try/catch` با ثبت هشدار.

### ۷. `created_at` بدون `DEFAULT` — خطای ۱۳۶۴

۲۷ جدول `created_at NOT NULL` بدون مقدار پیش‌فرض داشتند؛ هر مسیر درج/مهاجرت
جدیدی که آن را ست نکند در `STRICT_TRANS_TABLES` می‌شکست.
**رفع:** همهٔ ستون‌های `created_at` حالا `DEFAULT CURRENT_TIMESTAMP` دارند
(برنامه هنوز مقدار را صریح می‌فرستد؛ این فقط تور محافظ است).

## مواردی که بررسی و سالم تشخیص داده شد

| مورد | نتیجه |
|---|---|
| کلمات رزروشده در ستون‌ها | فقط `key` و `rank` — `key` رفع شد، `rank` همه‌جا با backtick |
| طول ایندکس UNIQUE (محدودیت ۳۰۷۲ بایت utf8mb4) | همهٔ ۱۹ قید UNIQUE زیر حد مجاز |
| `TEXT`/`JSON` در ایندکس | هیچ‌کدام ایندکس نمی‌شوند |
| ترتیب ساخت جدول‌ها (کلید خارجی) | هر ۲۱ کلید خارجی به جدول قبلی اشاره می‌کند |
| نوع ستون‌های کلید خارجی | همه `BIGINT UNSIGNED` و هم‌نوع با مرجع |
| `LIMIT :param` (در MySQL با emulate=false خطا می‌دهد) | صفر مورد — همه با `(int)` تزریق می‌شوند |
| تزریق SQL در `$whereSql`، `$metric`، `$column` | همه از whitelist یا پارامتر بسته‌شده |
| `CAST(telegram_id AS CHAR)` | سازگار با هر دو |
| `REPLACE INTO` / `INSERT IGNORE` / `ON DUPLICATE KEY` | صفر مورد |
| `FOR UPDATE` برای قفل ردیف مالی | درست پیاده‌سازی شده (SQLite: بدون قفل لازم) |
| تراکنش تودرتو با SAVEPOINT | درست |
| `sql_mode` با `ONLY_FULL_GROUP_BY` | کوئری‌ها با آن سازگارند |

## اجرای تست

```bash
php tests/_mysql_ddl.php     # ۱۱ بررسی سازگاری MySQL (بدون نیاز به سرور MySQL)
php tests/run_all.php        # کل تست‌ها
```

## محدودیت صادقانه

این تست DDL را **بدون سرور MySQL** بررسی می‌کند. اگرچه هر سه باگ مسدودکننده
که پیدا شد اکنون پوشش داده شده‌اند، **اولین نصب واقعی روی MySQL را باید
روی همان هاست خودتان انجام دهید** و لاگ خطا (اگر بود) را بررسی کنید.
توصیه: پیش از تحویل به کارفرما یک بار روی یک دیتابیس MySQL آزمایشی
(`install.php` را کامل کنید)، سپس جداول را پاک و نصب واقعی را انجام دهید.
